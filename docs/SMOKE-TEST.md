# 冒烟测试清单

每次大改动（重构、批量修 bug）之后过一遍。全绿才算过关。

1. 打开 `play-main.html`：飞船贴地站立、HUD 数字正常、控制台无报错。
2. 按 E 点火起飞：推重比 > 1，能离开地面；A/D 旋转跟手，↑↓ 调油门。
3. 轻轻着陆：部件栏全绿；故意摔一跤：部件掉血、出碎片，`任务结算` 弹成就。
4. 把发动机摔毁后按 E：应提示「没有能用的发动机」，点不着火。
5. 把所有部件摔光：应弹「任务失败」，转向/油门/点火全部无效，按 R 恢复满状态。
6. S 存档 → 刷新 → L 读档：位置/燃料/油门恢复；缩到最小能看全整个星球。
7. `python server.py` 起服：build.html 改船保存 → 回 play-main 刷新，新船生效、贴地完好、部件栏百分比正常（不是全 0%）。
8. 换船后故意撞毁部件 → 刷新页面：损毁状态被任务存档恢复，不「奇迹复原」。
9. 双端协同：一台操控一台观战；观战端按 S 应提示「观战端不能存档」，共享存档不被覆盖。
10. 操控端锁屏 20 秒后解锁：日志出现「掉线期间操控权已被接管，回归后降级为观战」，不出现双操控端互跳。
11. 100x 加速下飞船始终留在屏幕内（相机跟得住）；从最近缩到最远各档位切换，帧率无明显变化（渲染描边已全部走屏幕空间）。
12. 点火上升全程帧率平稳（无每 0.1 秒一次的顿挫）；100x 下旋转/油门按真实时间响应——转半圈约 1 秒，和 1x 手感一致。
13. 造船厂装降落伞 → 试飞：下落到 10km 以下按 P 展开能看到伞并明显减速，再按 P 切断，落地后自动重新包好；横着砸地会弹「姿态不正」警告且不给着陆成就，低速度落地有轻微弹跳。
14. 造船厂里悬空放置部件会被拒绝（预览变红）；试飞时若仍有悬空件会提示「有 N 个部件悬空」；带悬空件的旧存档载入时自动修整并提示。
16. 分级系统：造船厂装分离器和降落伞（右下「分级」面板可 ◀▶ 调整归属）→ 发射后左下角出现分级堆栈（下一级高亮）→ 按空格激活下一级（切分离器 + 开该级伞），堆栈同步变灰；V 键切换查看各截；全部分级用尽后空格提示「所有分级已用尽」。
15. 多飞船：造一艘带控制舱和降落伞的船，发射后炸断（或再发射一艘新船）——V 键（触控「切船」）应在多艘船间循环接管，残骸会翻滚、船与船相撞会互相弹开并掉血；造船厂再发射新船时旧船原位保留不被覆盖（发射台被占则新船沿表面挪开）；观察站上每艘带控制舱的船都有「进入并操控」，点击后直接接管那艘。
17. ESC 暂停菜单：游戏中按 ESC（或点右上「☰ 菜单」）画面冻结、弹出菜单卡；点「继续游戏」/遮罩/再按 ESC 恢复，恢复后时间倍率档不变；菜单开着时空格/E/S 等游戏键全部无效；「返回主菜单」跳 index.html，再「开始游戏」回来进度还在（pagehide 自动存任务档）。
18. 星空与天空：贴地时背景蓝天、无星星；点火升空背景渐暗、星星渐显；入轨后满天星（含少量十字亮星）；平移镜头近层星星有轻微视差、缩放时星星不乱跳、100x 时间加速不狂流；暂停时星空静止。
