01 / 关于这个项目

火箭不是往上飞的

大部分人第一次玩，都会把火箭直直地往天上怼 —— 然后发现燃料烧光了也进不了轨道。

真正的做法是「重力转向」：先垂直爬出稠密大气，然后慢慢压弯， 让火箭一边被引力拉着往下掉、一边加速到横向速度 —— 当你横着飞得足够快， 「往下掉」的曲线就永远够不到地面了。这就是轨道。

MSP-2D 把这一整套东西做进了一个网页里：真实的万有引力、指数衰减的大气、 速度平方的空气阻力、再入时的气动加热、多级火箭分离、降落伞减速。

整个游戏就是一个静态网页 + 一个 Python 标准库服务器，没有框架、没有构建工具。

02 / 有什么好玩的
🚀

造船厂

拖拽零件组装火箭。控制舱、燃料箱、发动机、分离器、降落伞，几十种组合。

🌍

真实引力

平方反比引力，随高度衰减。绕圈、转移轨道、逃逸，全都按牛顿算。

🔥

再入加热

速度太快冲进大气会烧起来。每个部件有各自的耐热上限，烧穿了就炸。

✂️

多级分离

按空格切断分离器，下级沿船轴抛离。分离出去的残骸继续保持惯性飞。

🪂

降落伞

按 P 展开，减速实时取决于大气密度。高空几乎没用，越往下越猛。

⏱️

时间加速

1x 到 100x。轨道周期动辄几千秒，不加速根本等不起。

📈

轨道预测

实时画出你的飞行轨迹，包含引力和大气阻力。落点看得见。

📱

手机也能玩

触控按键自动适配。同一个 WiFi 下，手机浏览器直接打开就能玩。

04 / 底下是怎么算的

游戏里没有任何「手感调参」。所有数字都是从真实物理推出来的 —— 想要飞得高，只能靠算。

引力
g = g₀ · (R / r)²

地表 3.71 m/s²（火星级别）。离地面越远越弱，平方反比。飞出大气后就是纯二体问题。

大气
ρ = e−h / H

标高 H = 23.1 km，120 km 处密度约 0.5%。再往上就不再计算阻力了 —— 不是硬墙，是真的没了。

空气阻力
F = k · ρ · v²

速度平方。所以高速再入时阻力巨大，能把你直接减速到落体速度以下。

降落伞
F = k · A · ρ · v²

和空气阻力同一套公式，只是等效面积 A 大得多。所以高空几乎没用，越往下越猛。

再入加热
Q ∝ v · ρ

速度乘以密度。只有「高速 + 稠密大气」才会烧起来 —— 垂直往下掉反而不会。

质量变化
a = F / (m₀ + mfuel)

油烧掉了船就变轻，同样的油门加速度更快。齐奥尔科夫斯基方程说的就是这件事。

怎么玩
  1. 1 解压到一个文件夹
  2. 2 装 Python（安装时勾选 Add Python to PATH）
  3. 3 在文件夹里打开命令行，运行： 
python server.py

浏览器会自动打开。也可以手动访问 http://localhost:8080/play-main.html

同一个 WiFi 下的手机也能玩 —— 服务器启动时会打印局域网地址。
