# MSP-2D

**Meows Space Project** 的 2D 网页版 —— 一个开火箭、绕轨道、算引力的小游戏。

## 怎么玩

```bash
python server.py
```

然后浏览器打开 <http://localhost:8080/play-main.html>

同一 WiFi 下的手机 / 平板也能玩：`http://<你的局域网IP>:8080/play-main.html`
（启动时终端会打印这个地址）

## 玩法要点

1. **起飞** —— 按 `E` 点火。默认船满油推重比 **2.34:1**（空油 3.58:1）。
   真实火箭只有 1.3~1.5:1,这里比现实略高,留了一点余量,又不像以前 4.7:1 那样像街机。
   点火 3 秒升到约 22 m,5 秒约 63 m。
2. **关机就能停** —— 关机后靠重力刹车，速度每秒掉约 **3.7 m/s**
   （5 秒点火到 25 m/s，约 7 秒就把速度减到 0）。减速时间 ≈ v/g，
   想要更利落就少点火几秒。
3. **变轻** —— 燃料在烧,飞船在变轻。同样油门,飞得越久加速越快:
   默认船满油 115 单位 → 空油 75 单位。
4. **入轨** —— 别垂直猛冲。升到一定高度后**掉头朝水平**,
   加速到 HUD 上的「圆轨道速度」就成功了。
   圆轨道速度约 **3045 m/s（≈3.05 km/s）**,逃逸速度约 **4307 m/s（≈4.31 km/s）**。
   满油门水平加速到入轨速度约需 **320 秒**,燃料够烧 **680 秒**。
5. **着陆** —— 掉头朝星球点火下降,扎地速度低于 180 就稳落,落地自动关机。
6. **再起飞** —— 停稳后掉头朝上,按 `E` 又飞了。

蓝色虚线是**轨道预测**，它会跟着油门和燃料一起算 —— 所见即所得。

## 造船厂（build.html）

游戏里的飞船不再是一个箭头 —— **你自己拼**。

打开 <http://localhost:8080/build.html>（或主菜单点「造船厂」）：

- 左侧部件库点一下 → 在画布上点一下就放下
- 拖动已放置的部件可以移动
- **镜像对称**开着时，放在中轴右边的部件会自动在左边生成一个
- 右侧实时显示质量 / 燃料 / 推力 / 推重比
- 校验不通过（没控制舱、没发动机、部件重叠）会提示，不让你发射
- 点「试飞」直接进游戏

### 部件

| 部件 | 尺寸 | 质量 | 燃料 | 推力 | 说明 |
|---|---|---|---|---|---|
| 控制舱 | 2×2 | 30 | — | — | 必须有，没它不能驾驶 |
| 燃料箱 | 2×3 | 20 | +40 | — | 装燃料，也是「变轻」的来源 |
| 发动机 | 2×2 | 25 | — | 40 | 必须有，没它飞不起来 |

**质量 = Σ部件质量 + 剩余燃料**，所以燃料烧掉多少，飞船就轻多少。

飞船存在 `localStorage`（浏览器本地）和服务器 `ship.json`（两个都存），
手机造的船电脑上也能直接飞。

数据结构见 [SHIP-FORMAT.md](SHIP-FORMAT.md)。

## 星球设定（真实物理）

这颗星球的参数**全部按真实物理互相约束**,不能单独改:

| 量 | 值 | 说明 |
|---|---|---|
| 表面重力 | **3.71 m/s²** | 火星表面重力 |
| 半径 | **2500 km** | |
| 密度 | **5.31 g/cm³** | 岩石行星,`3g/(4πGR)`(火星 3.9,地球 5.5) |
| 逃逸速度 | **4307 m/s** | `√(2gR)`,充分留住 O₂/N₂ |
| 表面温度 | **288 K (15°C)** | 猫咪能活 |
| 圆轨道速度 | **3045 m/s** | `√(gR)` |
| 大气标高 | **23.1 km** | `kT/(mg)` |

**为什么是这几个数**:大气存在需要逃逸速度 ≳ 6 倍气体热运动速度。
288 K 下 O₂ 热速度 474 m/s,N₂ 是 507 m/s —— 要留住它们,`√(2gR)` 必须 ≥ ~3000 m/s。
3.71 m/s² × 2500 km 满足(比值 N₂ 8.5,O₂ 9.1)。

**重力为什么是 3.71 而不是更小**:减速时间 ≈ v/g,重力太小时飞船
"关机后要滑行一分多钟才停"。1.35 时 5 秒点火要 91 秒落地,3.71 时只要 42 秒。
而且低速时空气阻力 ∝ v² 几乎为零,**只能靠重力刹车**。

改重力会改密度,改半径会改逃逸速度(进而决定大气能不能留住)——
**这三个量是锁在一起的**,想改就得整套重算。

## 大气层与再入

大气用**指数衰减**:密度 = `exp(-高度 / 标高)`。标高按真实公式 `H = kT/(mg)` 算出:

```
H = 1.381e-23 × 288 / (28 × 1.661e-27 × 3.71) = 23.1 km
```

| 高度 | 密度 |
|---|---|
| 0 km | 100% |
| 16 km | 50% |
| 23 km | 37%(1 个标高) |
| 46 km | 14% |
| 69 km | 5% |
| 120 km | 0.6%(参考线「大气顶」) |
| 200 km | 0.02%(基本真空) |

**阻力系数按终端速度定**:`CAP = G0 / v_term²`,取终端速度 800 m/s → `CAP = 2.9e-4`。
(终端速度 = 阻力等于重力时的速度,即自由落体的最大速度)

- 低空有明显刹车,高速再入会被大气剧烈减速
- 点火上升时阻力打三折,避免被大气拖得难受
- **高速冲回大气会升温**,而且是**逐部件**的:
  迎着气流的那一面先烧起来,温度到阈值就炸
- 各部件耐热不同:**控制舱(返回舱)900°C** > 发动机 420°C > 燃料箱 260°C
  —— 所以燃料箱最先烧穿,返回舱能撑到最后

## 损毁与分离

撞太狠或者烧太狠，部件会炸：

- **撞地**：超过 120 px/s 开始损伤，超过 420 px/s 当场炸毁
- **烧毁**：温度超过各自阈值
- **燃料箱炸了，里面的油一起没**
- 部件炸断中间后，**飞船分离成多个航天器**（用并查集找还连在一起的部件）
  - 有控制舱的那一截继续由你操控
  - 其余变成**失控残骸**，按惯性自己飞，撞地会停下

**R 键重置**：飞丢了、炸惨了、卡住了，按 `R` 修复全部件、满油、放回地面。

## 喵星地面观察站（station.html）

<http://localhost:8080/station.html>

- 列出所有航天器：你在操控的那艘 + 分离出去的失控残骸
- 显示每艘的部件（炸掉的划掉）、高度、速度、燃料、角度
- **有控制舱的可以「进入并操控」，没有的只能「进入（只读）」**
- 观察站是只读端，不会抢走游戏端的操控权

## 多端协同（服主分配操控 / 观战）

多台设备可以连同一个服务器共享同一个世界：被设为「操控」的那台能开飞船，其它端变成**观战**，画面跟着操控端一起动。

**服主控制台**：在跑 `server.py` 那台电脑上打开 <http://localhost:8080/admin>

- 列出所有连接端（IP、状态、空闲时间、角色）
- 把任意一端设为 **操控 / 观战**，或**踢出**
- 操控端同一时间只有一个；没有任何操控端时，第一个连上的会自动接管
- 角色设置会存盘，重启服务器后依然有效

**观战端**：按键和触控全部被拦截，屏幕左侧显示「观战中」，HUD 显示在线端数。

## 物理参数速查

都在 `play-main.html` 顶部，想调手感改这里：

| 参数 | 值 | 作用 |
|---|---|---|
| `SURFACE_GRAVITY_MS2` | 3.71 | 表面引力（米/秒²，唯一数据源） |
| `M_PER_PX` | 1 | 全局比例：1 像素 = 1 米（默认船 14 × 49 m，正常火箭大小） |
| `PLANET_RADIUS_KM` | 2500 | 星球真实半径 |
| `DRY_MASS` / `FUEL_MASS` | 75 / 40 | 空船质量 / 满油燃料质量（由部件算出） |
| `FULL_THRUST` | 1000 | 满油门推力（÷质量 = 加速度；每台发动机 1000） |
| `FUEL_BURN_SECONDS` | 680 | 满油门烧完一箱油要多久 |
| `ATMO_SCALE_HEIGHT_KM` | 23.1 | 大气标高（`kT/mg` 算出） |
| `DRAG_COEF` | 2.6e-6 | 阻力系数（按终端速度 1200 m/s 定） |
| `LANDING_SPEED` | 180 | 扎地速度低于它就稳落（米/秒） |
| `GROUND_FRICTION` | 0.85 | 地面摩擦 |
| `ROTATE_SPEED` | 90 | 转向速度（度/秒） |
| `ZOOM_RATE_PER_SEC` | 0.25 | 按住缩放键的速度 |

引力用的是**平方反比**（和真实星球一样）：`引力 = G0_PX × (radius / 距离)²`

其中 `G0_PX = SURFACE_GRAVITY_MS2 / M_PER_PX = 3.71` 像素/秒²，
是物理实际使用的值。**HUD 上的圆轨道速度、推重比、轨道根数全部由它派生**，
想改星球轻重只改 `SURFACE_GRAVITY_MS2` 一个数即可。
