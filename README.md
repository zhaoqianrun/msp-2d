# MSP-2D

**Meows Space Project** 的 2D 网页版 —— 一个开火箭、绕轨道、算引力的小游戏。

## 怎么玩

```bash
python server.py
```

然后浏览器打开 <http://localhost:8080/play-main.html>

同一 WiFi 下的手机 / 平板也能玩：`http://<你的局域网IP>:8080/play-main.html`
（启动时终端会打印这个地址）

| 操作 | 键盘 | 触控 |
|---|---|---|
| 点火 / 关机 | `E` | 「点火」按钮 |
| 左转 / 右转 | `A` / `D` | 「左转」「右转」 |
| 油门 − / ＋ | `↓` / `↑`（按住 `Shift` 微调） | 「油门−」「油门＋」「微调」 |

| 协同信息 | — | 右上角「协同」 |

## 玩法要点

1. **起飞** —— 按 `E` 点火。推重比只有 1.5:1，所以起飞不算猛，但稳。
2. **变轻** —— 燃料在烧，飞船在变轻。同样油门，飞得越久加速越快（质量 120 → 60，加速度 300 → 600）。
3. **入轨** —— 别垂直猛冲。升到一定高度后**掉头朝水平**，加速到 HUD 上的「圆轨道速度」，虚线闭合就成功了。
4. **着陆** —— 掉头朝星球点火下降，扎地速度低于 180 就稳落，落地自动关机。
5. **再起飞** —— 停稳后掉头朝上，按 `E` 又飞了。

蓝色虚线是**轨道预测**，它会跟着油门和燃料一起算 —— 所见即所得。

## 造船厂（build.html）

游戏里的飞船不再是一个箭头 —— **你自己拼**。

打开 <http://localhost:8080/build.html>（或主菜单点「造船厂」）：

- 左侧部件库点一下 → 在画布上点一下就放下
- 拖动已放置的部件可以移动
- **镜像对称**开着时，放在中轴右边的部件会自动在左边生成一个
- 右侧实时显示质量 / 燃料 / 推力 / 推重比
- 校验不通过（没控制舱、没发动机、部件重叠）会提示，不让你发射
- 点「试飞」直接进游戏

### 部件

| 部件 | 尺寸 | 质量 | 燃料 | 推力 | 说明 |
|---|---|---|---|---|---|
| 控制舱 | 2×2 | 30 | — | — | 必须有，没它不能驾驶 |
| 燃料箱 | 2×3 | 20 | +40 | — | 装燃料，也是「变轻」的来源 |
| 发动机 | 2×2 | 25 | — | 80000 | 必须有，没它飞不起来 |

**质量 = Σ部件质量 + 剩余燃料**，所以燃料烧掉多少，飞船就轻多少。

飞船存在 `localStorage`（浏览器本地）和服务器 `ship.json`（两个都存），
手机造的船电脑上也能直接飞。

数据结构见 [SHIP-FORMAT.md](SHIP-FORMAT.md)。

## 多端协同（服主分配操控 / 观战）

多台设备可以连同一个服务器共享同一个世界：被设为「操控」的那台能开飞船，其它端变成**观战**，画面跟着操控端一起动。

**服主控制台**：在跑 `server.py` 那台电脑上打开 <http://localhost:8080/admin>

- 列出所有连接端（IP、状态、空闲时间、角色）
- 把任意一端设为 **操控 / 观战**，或**踢出**
- 操控端同一时间只有一个；没有任何操控端时，第一个连上的会自动接管
- 角色设置会存盘，重启服务器后依然有效

**观战端**：按键和触控全部被拦截，屏幕左侧显示「观战中」，HUD 显示在线端数。

## 成就

21 个，**着陆时统一结算**（唯一例外是「弹尽粮绝」，烧干油当场就弹）。
按 `C` 查看进度。

## 物理参数速查

都在 `play-main.html` 顶部，想调手感改这里：

| 参数 | 值 | 作用 |
|---|---|---|
| `planet.surfaceGravity` | 200 | 贴地引力 |
| `DRY_MASS` / `FUEL_MASS` | 60 / 60 | 空船质量 / 满油燃料质量 |
| `FULL_THRUST` | 36000 | 满油门推力（÷质量 = 加速度） |
| `FUEL_BURN_SECONDS` | 120 | 满油门烧完一箱油要多久 |
| `LANDING_SPEED` | 180 | 扎地速度低于它就稳落 |
| `GROUND_FRICTION` | 0.85 | 地面摩擦 |
| `ROTATE_SPEED` | 180 | 转向速度（度/秒） |
| `ZOOM_RATE_PER_SEC` | 0.25 | 按住缩放键的速度 |

引力用的是**平方反比**（和真实星球一样）：`引力 = surfaceGravity × (radius / 距离)²`
